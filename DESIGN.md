# BuildWhat Test Design System

A small, public design-system fixture used to verify GitHub imports in BuildWhat.

## Brand

- Calm, technical, high-contrast.
- Primary accent: blue.
- Surfaces: white with a light neutral border.

## Color

| Token | Value |
| --- | --- |
| background | #ffffff |
| text | #111111 |
| accent | #2563eb |
| border | #e5e7eb |

## Typography

- Sans: Inter
- Mono: ui-monospace
- Base size: 16px
- Weights: 400 / 600

## Spacing

Use a 4px base scale: 4 / 8 / 16 / 24.

## Radius

- Small: 4px
- Medium: 8px
- Large: 16px

## Components

- Button
- Card
- Input
